**F-50 카테고리 관리**
- 지출/수입 각각 추가, 이름 변경, 아이콘 선택(Lucide 아이콘 목록 중), 순서 변경(`위로`/`아래로` 버튼, 키보드 조작 가능), 숨기기.
- 내역이 있는 카테고리는 삭제 대신 숨기기만 가능.

**F-51 계좌·카드 관리**
- 이름, 종류(카드/계좌/현금/기타), 소유(공동/A/B), 문자 인식용 별칭(예: "신한", "삼성카드").
- 웹 사이드바의 "함께 보는 계좌·카드"에 표시되고, 누르면 그 결제수단으로 필터된 내역 화면으로 간다.

**F-52 엑셀 내보내기(백업)** (2차, 2026-10-01 사용자 결정으로 CSV → 엑셀, 내역 → 여러 데이터)
- 목적: 앱이나 Supabase에 문제가 생겨도 데이터가 파일로 남는 **보관용 백업**. 엑셀로 열어 볼 수 있다. 앱으로 다시 불러오기는 없다.
- 설정 메뉴 `데이터 내보내기` → `/settings/export`: 담기는 시트, 지운 항목·메모·일정은 빠진다는 설명 + `엑셀로 내보내기` 버튼. 두 사람 모두 받을 수 있다.
- 기간 선택 없음: 늘 처음부터 지금까지 전체(사용자 결정).
- 버튼은 일반 다운로드 링크(`/api/export`, 아이폰 홈 화면 앱에서도 받기 위해). 서버가 로그인한 사람의 가구 데이터를 RLS 그대로 읽어 엑셀 파일(`.xlsx`)을 바로 내려준다. 파일은 어디에도 저장하지 않는다. 파일 이름 `감자밭-백업-2026-10-01.xlsx`(오늘, KST).
- 로그인하지 않았으면 로그인 화면으로, 읽기·만들기에 실패하면 "내보내기에 실패했어요. 잠시 뒤 다시 해 주세요." (상태 500, 글자).
- 시트·열은 §8.3. 라이브러리 `write-excel-file`(서버용 `/node`).
- 가져오기: **제외됨** (2026-09-27 사용자 결정, §8.2).

**F-54 서비스 사용량** (2차)
- 설정 화면에 "서비스 사용량" 칸: Supabase 데이터베이스 용량(무료 500MB 대비), 우리 가구 내역·정기지출 개수, 마지막 사용 시각.
- "무료 프로젝트는 7일 동안 요청이 없으면 일시 정지돼요" 안내.
- Supabase·Vercel 사용량 페이지로 가는 링크. Vercel 사용량은 별도 토큰이 필요해 앱 안에 숫자로 보여주지 않는다.
- Claude 사용량(개발에 쓰는 Claude 구독) 페이지(claude.ai/settings/usage)로 가는 링크 (2026-09-28 추가). 구독 사용량은 가져오는 공개 API가 없어 숫자로 보여주지 않는다.

**F-55 공휴일 관리** (2026-09-29 추가)
- 기본 공휴일은 라이브러리 `@hyunbinseo/holidays-kr`(정부 월력요항 기준, 대체공휴일·설·추석 포함)에서 온다. 새 해 공휴일은 **설정 → 공휴일의 "최신 공휴일 받기"**로 받는다(2026-09-29 추가): 라이브러리가 올려 두는 파일(`https://holidays.hyunbin.page/basic.json`)을 서버가 받아 형식을 검사한 뒤 `holiday_presets`에 저장하고, 저장된 해는 이 데이터를, 없는 해는 설치된 라이브러리를 쓴다. 내년 공휴일이 아직 없으면 이 화면을 열 때 하루 한 번까지 자동으로 받는다. 파일을 못 받거나 형식이 이상하면 아무것도 바꾸지 않는다. 마지막으로 받은 날을 보여준다. 둘 다 없는 해는 안내를 보여주고, 주말과 직접 추가한 날만으로 계산한다.
- 설정 → 공휴일(`/settings/holidays`): 연도 이동, 그 해 공휴일 목록(이름·날짜·요일). 기본 공휴일은 "쉬는 날 아님"으로 빼고 "다시 쉬는 날로" 되돌릴 수 있다. 임시공휴일·회사 휴무는 "공휴일 추가"(날짜 + 이름 20자)로 넣고, 삭제(되돌리기 가능).
- 받아 온 공휴일은 가구와 관계없는 공통 데이터 `holiday_presets`(날짜, 해, 이름들) + `holiday_sync`(받은·확인한 시각). 로그인하면 읽기만, 쓰기는 서버(서비스 키).
- 가구마다 고친 것만 `custom_holidays`에 저장(추가/빼기, 같은 날짜는 하나만, 소프트 삭제). 두 사람이 같은 목록을 쓴다.
- 일정 달력: 공휴일 날짜 숫자를 `holiday` 색으로, 웹은 칸에 이름도. 날짜를 고르면 목록 위에 "공휴일 · 추석". 일정 달력은 실제 달력 그대로(한 달 기준을 따르지 않음).
- F-56(한 달 기준)의 "월급날이 주말·공휴일이면 앞 평일로 당기기"에 쓴다.

**F-56 한 달 기준** (2026-09-29 추가)
- 설정 → 한 달 기준(`/settings/period`): 시작일 1~28일(기본 1일 = 달력의 한 달, 지금과 같음), "주말·공휴일이면 앞 평일부터 시작"(기본 켜짐, 공휴일은 F-55), 달 이름(끝나는 달 = 기본 / 시작하는 달). 가구 하나에 하나의 기준.
- 규칙: 기간 시작일 = 그 달만 직접 고친 날 또는 월급날(당기기 적용). 이름이 "끝나는 달"이면 "10월" = 9월 월급날부터. 종료일 = 다음 달 시작일 전날이라 겹치거나 빠지는 날이 없다.
- 달마다 기간: 지난달~석 달 뒤 기간을 보여주고, 그 달만 시작일 바꾸기·원래대로. 앞 달 시작일보다 뒤, 다음 달 시작일보다 앞이어야 한다.
- 따르는 화면: 홈(이번 달 지출·지난달 같은 기간 비교·예산), 예산(남은 일수·하루 예산 포함), 통계(6개월·카테고리·사람), 내역(월 이동·목록·달력은 기간만 그리고 첫날과 1일은 "10/1"), 정기지출(체크리스트와 결제일: 기간 안의 그 날짜, 예: 매월 1일 → 10/1), 순자산 추이(각 기간 마지막 날). 머리에 기간(예: "9/25~10/24", 1일 기준이면 표시 안 함, 폰은 내역 달력 줄·통계 위쪽에).
- 예외: 일정 달력은 실제 달력 그대로(공휴일 표시만).
- 알림을 누르면 month 없이 날짜만 넘겨(`?day=`, 문자 묶음은 `?at=`) 내역 화면이 그 날짜가 든 기간을 연다.
- 예산·통장·카드 예산·정기지출 체크는 달 이름(yyyy-MM-01)으로 저장하므로 기존 데이터는 그대로다. 나중에 시작일을 바꾸면 지난 기록이 새 기준의 기간으로 다시 계산된다.
- 데이터: `households.period_start_day / period_label / period_shift`(바꾸기는 `set_period_settings()`), `period_overrides`(가구, 달 이름, 시작일, RLS). 내보내기(F-52)는 설정값을 담지 않는다.

**F-57 휴대폰 알림** (2026-09-29 추가)
- 앱 안 알림(F-17)과 **같은 알림을 같은 문장으로** 폰 잠금 화면에도 보낸다. 누르면 그 내역·메모·일정이 열린다. 방해 금지 시간은 없다(사용자 결정). 같은 내역 알림은 폰에서 하나로 겹친다(tag). 같은 내역을 여러 번 고쳐 안 읽은 알림 하나를 새로 고칠 때는 다시 보내지 않는다.
- 설정 → 휴대폰 알림(`/settings/push`): 기기마다 "이 폰에서 알림 받기"(권한 요청 → 알림 주소 저장), "시험 알림 보내기", "이 폰에서 알림 끄기", 알림 받는 내 기기 목록. 아이폰은 iOS 16.4 이상 + 홈 화면에 추가한 앱에서만 된다(아니면 안내). 막혀 있으면 폰 설정에서 허용하라는 안내.
- 구조: 웹 푸시(VAPID 키, 라이브러리 `web-push`). 알림 전용 서비스 워커 `public/sw.js`(오프라인 캐시는 하지 않음). 앱 안 알림이 새로 생기면 DB 트리거가 `pg_net`으로 운영 서버 `/api/push`에 **알림 번호만** 넘기고, 서버가 서비스 키로 다시 읽어 **2분 안에 생겼고 아직 안 보낸 알림**만 `pushed_at` 표시 후 받는 사람의 기기들로 보낸다(주소가 알려져도 옛 알림 재전송·스팸 불가). 사라진 기기(404·410)는 지운다. 운영 주소로만 보낸다(개발·미리보기에서는 안 감).
- 데이터: `push_subscriptions`(사람, 가구, 주소·키, 기기 이름, 마지막 알림 시각, RLS: 본인 것만), `notifications.pushed_at`. 환경변수: `VAPID_PUBLIC_KEY`(공개키, 서버가 설정 화면에 넘겨줌), `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`(Vercel에도).
- 사용량: 구글·애플의 알림 전달은 무료, 알림 1건에 서버 호출 1번이라 두 사람 사용량으로는 무료 한도에 비해 아주 작다.

**F-53 PWA·다크 모드** (3차)
- 홈 화면에 추가 가능한 PWA (아이콘, 이름, 전체화면).
- 다크 모드 수동 전환(시스템/라이트/다크). 시스템 설정을 따르는 다크 모드 자체는 M0부터 적용한다(디자인 토큰에 다크 값이 이미 있음).
- 결정 (2026-09-27): PWA는 먼저 배포함. 화면 모드는 설정 → "화면 모드"에서 고르고, **기기마다** 따로 저장한다(두 사람이 각자 원하는 모드).
