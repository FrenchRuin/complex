# 계정·가구 (F-01~04)

> `SPEC.md`(목차)의 일부. 원래 절 번호를 그대로 둔다.

### 3.1 계정·가구

| ID | 기능 | 우선순위 |
| --- | --- | --- |
| F-01 | 이메일 로그인, 미리 만든 두 계정만 사용 | MVP |
| F-02 | 가구 만들기, 초대 링크로 배우자 합류 (최대 2명) | MVP |
| F-03 | 프로필: 표시 이름, 사람 색(A/B 자동 지정) | MVP |
| F-04 | 오늘 기분 (사용자 요청, 2026-10-01 추가) | 개선 |

**F-01 로그인**
- 이메일과 비밀번호로 로그인한다. 앱에는 회원가입 화면이 없다.
- 두 계정은 Supabase 대시보드(Authentication → Users → Add user, 이메일 자동 확인)에서 미리 만들고, 새 가입(Allow new users to sign up)은 끈다.
- 이중 안전장치: 허용 이메일 목록(서버 환경변수 `ALLOWED_EMAILS`, 쉼표 구분)에 없는 계정은 로그인 직후 로그아웃시키고 "초대받은 계정만 사용할 수 있어요"를 보여준다.
- 로그인 실패 시 "이메일 또는 비밀번호가 맞지 않아요"를 보여준다.
- 비밀번호를 잊으면 대시보드에서 바꾼다(앱 안의 비밀번호 찾기 없음).
- 로그인 상태는 유지된다(매번 다시 로그인하지 않음). 로그아웃은 설정 화면에서.

**F-02 가구 연결**
- 처음 로그인한 사람은 가구가 없으면 "가구 만들기" 화면을 본다. 가구를 만들면 그 사람이 A가 된다.
- A는 설정에서 초대 링크를 만들 수 있다. 링크는 7일간 유효하고 한 번만 쓸 수 있다.
- 초대 링크로 들어온 사람은 로그인 후 B로 합류한다. 가구 인원이 2명이면 초대 링크를 더 만들 수 없다.
- 가구가 만들어질 때 기본 카테고리(§7)와 기본 결제수단("현금")을 넣는다.

**F-03 프로필**
- 표시 이름(최대 10자)을 바꿀 수 있다. 앱의 모든 곳에서 이 이름으로 부른다.
- 사람 색은 A = 청록(`member-a`), B = 주황(`member-b`), 공동 = 슬레이트(`joint`)로 고정한다.
- 프로필 사진(2026-09-28 추가): jpg/png/webp, 5MB까지. 새로 올리면 이전 사진을 지운다. 사진이 없으면 이름 첫 글자 아바타. 사이드바 아바타에 반영된다(모바일은 아바타를 쓰는 곳이 아직 없음).

**F-04 오늘 기분** (2026-10-01 추가)
- 목적: 둘이 가볍게 오늘 마음을 주고받는다. 가계부 계산과는 관계없다.
- 고르기: 사이드바 맨 아래 내 프로필 줄(웹 사이드바, 폰 메뉴)을 누르면 작은 창. 접힌 사이드바는 이모지만 보이고, 고르려면 펼친다. 홈의 내 기분 칸을 눌러도 같은 창.
  - 정해진 이모지 12개 중 하나 (이모지 + 이름 글자, 4열 격자): 😊 좋아요, 🥰 행복해요, 😆 신나요, 😌 평온해요, 😐 그저 그래요, 😴 피곤해요, 😵 바빠요, 😤 짜증나요, 😢 슬퍼요, 🤒 아파요, 🍚 배고파요, 🥳 축하해요.
  - 한 줄 메모는 선택, 20자까지 (앞뒤 공백 지움, 빈 글은 없음으로).
  - 버튼: `저장`, 오늘 기분이 있으면 `기분 지우기`. 이모지를 고르지 않으면 저장할 수 없다.
- 오늘만: 한국 시각 날짜별로 저장하고, 화면에는 오늘 날짜 것만 보인다. 다음 날 0시가 지나면 자동으로 안 보인다 (지우는 작업 없음). 지난 기분을 보는 화면은 없다 (나중에 달력 표시를 붙일 수 있게 날짜별로 남겨 둔다).
- 보이는 곳:
  - 홈 위쪽: 두 사람 기분 한 줄씩 (`이름 😴 피곤해요 · 야근 중`). 안 정했으면 "아직 안 정했어요". 내 칸은 눌러서 고를 수 있다. 혼자인 가구는 내 칸만.
  - 사이드바 위 두 사람 아바타: 오른쪽 아래에 이모지 배지. 접힌 사이드바의 내 아바타도.
  - 사이드바 아래 내 프로필 줄: 이름 옆에 이모지.
  - 이모지에는 항상 이름 글자(스크린리더용 `aria-label` 포함)를 함께 둔다.
  - 상대가 바꾸면 실시간으로 바로 바뀐다.
- 알림(F-17·F-57): 상대가 기분을 정하거나 바꾸면 "○○님이 오늘 기분을 🥰 행복해요로 정했어요"(메모가 있으면 뒤에 " · 야근 중"). 같은 날 여러 번 바꾸면 안 읽은 기분 알림 하나만 고친다. 같은 기분·메모로 다시 저장하거나 지우면 알림 없음. 알림을 누르면 홈으로.
- 권한(RLS): 같은 가구만 보고, 내 기분만 만들기·고치기·지우기.
- 문구 규칙 예외: 앱 문구에는 이모지를 쓰지 않지만, 사람이 고른 기분 이모지는 그대로 보여준다.
