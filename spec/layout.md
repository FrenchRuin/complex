## 4. 화면과 레이아웃

### 4.1 레이아웃

- **웹 (폭 1024px 이상)**: 왼쪽 사이드바 폭 248px 고정, 오른쪽 메인만 스크롤. 사이드바는 스크롤과 무관하게 항상 보인다. 메인 상단 헤더(월 전환, 사람 필터)는 메인 안에서 sticky.
- **모바일·태블릿 (1024px 미만)**: 사이드바 대신 하단 탭바(홈, 내역, 통계, 정기지출, 설정) + 오른쪽 아래 둥근 추가 버튼. 화면 제목 줄 왼쪽 끝 ☰를 누르면 사이드바와 같은 내용이 왼쪽에서 밀려 나온다(탭바에 없는 메모·자산·목표로 가는 길). 메뉴 항목을 누르거나 바깥을 누르면 닫힌다. (2026-09-28 사용자 요청)
- 참고 UI: Notion, Slack의 사이드바 구조 (워크스페이스 전환 → 검색 → 주요 버튼 → 메뉴 → 섹션 목록 → 하단 설정·프로필).
- 로딩 표시 (2026-09-28 추가): 메뉴를 옮기면 사이드바·탭바는 그대로 두고 메인 영역에 그 화면 모양의 뼈대를 먼저 보여준다(홈, 내역, 통계, 정기지출, 자산·목표, 설정, 설정 하위 화면). 버튼으로 하는 작업(저장 등)은 처리 중에 버튼 글자가 "○○하는 중"으로 바뀌고 도는 표시가 붙으며 다시 누를 수 없다. 버튼이 아닌 곳(내역 추가 창 전환, 정기지출 체크 등)의 처리 중 표시는 이번 범위에서 뺐다.

### 4.2 사이드바 구성 (웹)

1. 가구 표시: 두 사람 아바타 + 앱 이름 + 알림 종 (두 사람 이름 줄은 종에 가려 2026-09-28 뺐다. 폰 ☰ 메뉴에서는 종 대신 닫기)
2. 검색 (`⌘K`로 포커스, 웹만)
3. **내역 추가** 버튼 (primary)
4. 메뉴: 홈, 내역, 통계, 정기지출(미납 개수 배지), 예산, 일정, 메모, 자산·목표
5. 섹션 "함께 보는 계좌·카드": 결제수단 목록, 소유 색 점 + 소유자 이름, `+` 로 추가. 제목을 누르면 접고 편다(접으면 개수, 기기마다 기억). 4·5는 한 덩어리로 스크롤하고 1~3·6은 고정 (2026-09-30)
6. 하단: 로그인한 사람 아바타(동기화 상태 점) + 이름, 오른쪽 톱니바퀴 아이콘 = 설정 (2026-09-29 변경: "설정" 메뉴 줄을 없앰)
