## 4. 화면과 레이아웃

### 4.1 레이아웃

- **웹 (폭 1024px 이상)**: 왼쪽 사이드바 폭 248px 고정, 오른쪽 메인만 스크롤. 사이드바는 스크롤과 무관하게 항상 보인다. 메인 상단 헤더(월 전환, 사람 필터)는 메인 안에서 sticky.
  - 맨 위 한 줄 (2026-10-02 사용자 요청): 사이드바 머리 줄(`사이드바 접기` · `감자밭` · 알림 종)과 메인 상단 헤더의 높이·아래 선을 맞춰 화면 맨 위가 한 줄로 이어져 보이게 한다. 메인 상단 헤더 안의 버튼은 44px을 넘지 않는다.
  - 사이드바 접기 (2026-09-30 사용자 요청): 머리 줄 맨 왼쪽 접기 버튼으로 폭 64px 아이콘 줄로 접는다(머리 줄에는 같은 자리의 펼치기 버튼만, 그 아래 알림 종, 내역 추가 +, 메뉴 아이콘 + 미납 배지, 상대 아바타·접속 상태, 내 아바타·연결 상태, 설정). 아이콘에 마우스·키보드를 올리면 이름표. 검색·계좌·카드 목록은 접힌 동안 숨김, 접힌 상태에서 Ctrl K를 누르면 펼치고 검색칸으로. 접힘은 기기마다 쿠키(`sidebar-collapsed`)로 기억해 새로고침해도 깜빡임 없이 유지.
- **모바일·태블릿 (1024px 미만)**: 사이드바 대신 하단 탭바(홈, 내역, 통계, 정기지출, 설정) + 오른쪽 아래 둥근 추가 버튼. 화면 제목 줄 왼쪽 끝 ☰를 누르면 사이드바와 같은 내용이 왼쪽에서 밀려 나온다(탭바에 없는 메모·자산·목표로 가는 길). 메뉴 항목을 누르거나 바깥을 누르면 닫힌다. (2026-09-28 사용자 요청)
- 참고 UI: Notion, Slack의 사이드바 구조 (워크스페이스 전환 → 검색 → 주요 버튼 → 메뉴 → 섹션 목록 → 하단 설정·프로필).
- 로딩 표시 (2026-09-28 추가): 메뉴를 옮기면 사이드바·탭바는 그대로 두고 메인 영역에 그 화면 모양의 뼈대를 먼저 보여준다(홈, 내역, 통계, 정기지출, 자산·목표, 설정, 설정 하위 화면). 버튼으로 하는 작업(저장 등)은 처리 중에 버튼 글자가 "○○하는 중"으로 바뀌고 도는 표시가 붙으며 다시 누를 수 없다. 버튼이 아닌 곳(내역 추가 창 전환, 정기지출 체크 등)의 처리 중 표시는 이번 범위에서 뺐다.

### 4.2 사이드바 구성 (웹)

1. 머리 줄: `사이드바 접기` + 앱 이름 + 알림 종 (2026-10-02: 두 사람 아바타는 아래 6으로 옮김, 접기 버튼을 맨 왼쪽으로. 폰 ☰ 메뉴는 앱 이름 + 닫기)
2. 검색 (`⌘K`로 포커스, 웹만)
3. **내역 추가** 버튼 (primary). 그 아래 구분선으로 메뉴와 나눈다 (접힌 사이드바도 같음, 2026-09-30)
4. 메뉴: 홈, 내역, 통계, 정기지출(미납 개수 배지), 예산, 일정, 메모, 자산·목표, 대출(2026-09-30)
5. 섹션 "함께 보는 계좌·카드": 결제수단 목록, 소유 색 점 + 소유자 이름, `+` 로 추가. 제목을 누르면 접고 편다(접으면 개수, 기기마다 기억). 4·5는 한 덩어리로 스크롤하고 1~3·6은 고정 (2026-09-30)
6. 하단 (2026-10-02 변경): 위에 상대 줄(아바타 + 접속 점, 이름 + 오늘 기분, 아래 `접속 중`/`접속 안 함`), 맨 아래 로그인한 사람 아바타(동기화 상태 점) + 이름, 오른쪽 톱니바퀴 아이콘 = 설정 (2026-09-29 변경: "설정" 메뉴 줄을 없앰)
   - 접속 상태: 상대가 앱을 열어 둔 동안 "접속 중". Supabase Realtime Presence(채널 `presence:<가구 id>`)로만 알고 DB에는 남기지 않는다. 마지막 접속 시각은 보여 주지 않는다 (사용자 결정)
