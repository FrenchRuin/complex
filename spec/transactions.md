**F-10 내역 추가**
- 입력 항목:
  - 유형: 지출 / 수입 (기본 지출)
  - 금액 (필수, 1원 이상, 입력 중 천 단위 쉼표 표시, 숫자 키패드)
  - 날짜 (기본 오늘)
  - 카테고리 (필수, 유형별 목록)
  - 가맹점·내용 (선택, 최대 50자)
  - 메모 (선택, 최대 200자)
  - 결제수단 (선택)
  - 구분: 공동 / 개인 (기본값은 결제수단의 소유자를 따름: 공동 소유면 공동, 아니면 개인)
  - 결제한 사람: A / B (기본 로그인한 사람. 개인이면 "누구의 지출", 공동이면 "누가 결제")
- 저장 후 입력창을 비우고 "저장했어요" 토스트. "계속 추가"를 켜면 창을 닫지 않는다.
- 웹: 오른쪽 사이드 패널(폭 440px). 모바일: 바텀시트.
- 단축키(웹): `N` 새 내역, `Esc` 닫기, `⌘/Ctrl + Enter` 저장.

**F-11 수정·삭제**
- 목록에서 내역을 누르면 같은 패널이 편집 모드로 열린다.
- 두 사람 모두 모든 내역을 수정·삭제할 수 있다.
- 삭제는 패널 안에서 한 번 더 확인한다("한 번 더 누르면 삭제돼요"). 삭제는 소프트 삭제(`deleted_at`)이고, 삭제 직후 5초간 "되돌리기"를 제공한다.
- 편집 패널 아래에 "서연님이 9월 26일에 추가 · 지훈님이 수정"처럼 작성자/수정자를 보여준다.

**F-12 목록**
- 월 단위로 보고, 상단에서 이전/다음 달로 이동한다.
- 날짜별로 묶고, 묶음 제목에 그날 지출 합계(수입이 있으면 수입도)를 표시한다.
- 필터: 사람(전체/공동/A/B), 유형(전체/지출/수입), 카테고리(복수 선택), 결제수단(복수 선택).
  - "공동" 필터 = 공동 내역 전체. "A" 필터 = **A의 개인 내역만** (A가 결제한 공동 지출은 포함하지 않음).
- 검색: 가맹점·메모 부분 일치, 현재 월 기준. (전체 기간 검색은 2차)
- 필터 상태는 URL 쿼리에 저장해 새로고침해도 유지한다.

**F-13 캘린더**
- 월 달력에 날짜별 지출 합계를 짧게 표시한다(예: `8.7만`, 1만 미만은 `8,500`). 수입이 있는 날은 파란 글자로 `+310만`.
- 날짜를 누르면 목록이 그날 내역만 보여준다. 다시 누르면 해제.
- 웹은 내역 화면 왼쪽에 달력, 오른쪽에 목록. 모바일은 목록 위에 접을 수 있는 달력.

**F-14 실시간 동기화**
- 상대가 추가·수정·삭제한 내역이 새로고침 없이 반영된다 (Supabase Realtime).
- ~~홈 상단에 최근 활동 한 줄~~ → 알림(F-17)으로 바꿔 뺐다 (2026-09-28).
- 네트워크가 끊기면 상단에 "연결이 끊겼어요. 다시 연결하는 중" 표시.

**F-15 카드 문자 붙여넣기** (2차)
- 입력 패널의 "문자로 추가" 탭에 여러 건의 카드/은행 알림 문자를 한 번에 붙여넣는다.
- "인식하기"를 누르면 건별로 미리보기 행을 만든다: 날짜, 시간, 금액, 가맹점, 결제수단(카드사), 추천 카테고리, 구분, 결제한 사람.
- 각 행은 체크박스로 선택/해제하고 값을 고칠 수 있다. "N건 저장"으로 한 번에 저장한다.
- 인식 규칙은 §8.1.
- **중복 경고**: 같은 가구에 날짜 ±1일, 같은 금액, 같은 가맹점(공백·대소문자 무시)인 내역이 있으면 "이미 있는 내역 같아요" 표시, 기본 선택 해제.
- 취소 문자("취소" 포함)는 "취소 문자" 배지를 달고 기본 선택 해제. 저장하면 수입(환불)로 기록한다.

**F-16 카테고리 자동 추천** (2차)
- 사용자가 내역을 저장할 때 가맹점 → 카테고리 규칙을 기록한다(`merchant_rules`). 같은 가맹점이 다시 입력되면 그 카테고리를 기본값으로 쓴다.
- 규칙이 없으면 기본 키워드 사전(§8.1)으로 추천한다.
