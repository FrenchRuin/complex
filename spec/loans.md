# 대출 계산 (F-43)

> `SPEC.md`(목차)의 일부. 2026-09-30 사용자 요청으로 추가.

### 3.6 대출 계산 (개선)

| ID | 기능 | 우선순위 |
| --- | --- | --- |
| F-43 | 대출 계산: 우리 정보·기존 대출·집 후보로 매매·전세 최대 대출 금액 계산 | 개선 |

**목적**: 두 사람이 집을 알아볼 때 "이 집이면 얼마까지 빌릴 수 있고, 현금은 얼마 필요하고, 매달 얼마 갚는지"를 후보마다 바로 비교한다. 매매가 우선이고 전세도 같이 본다.

**범위 밖**: 실제 대출 신청·심사, 은행별 금리 비교, 정부 사이트에서 기준값 자동으로 받아오기, 알림, 계산 결과 저장, 2주택 이상.

## 1. 화면 (`/loans`)

- 메뉴: 사이드바·☰ 메뉴의 "자산·목표" 아래 "대출" (아이콘 `Landmark`). 탭바에는 넣지 않는다. 로딩 뼈대 있음.
- 화면 맨 위에 항상 안내 문구: "참고용 계산이에요. 실제 한도는 은행 심사, 신용점수, 보증기관 기준에 따라 달라요."
- 순서: **우리 정보** → **기존 대출** → **집 후보** → **기준값**.

### 1.1 우리 정보

- 두 사람 연소득 (각각, 원). 계산에는 **두 사람 합산**을 쓴다 (부부 공동 차주로 본다).
- 주택 보유: 무주택 / 1주택. 생애최초(체크, 무주택일 때만 켤 수 있음).
- 순자산: 자산 메뉴의 순자산을 그대로 보여준다 (읽기 전용, "자산 메뉴 기준" 표시). 정책대출 자산 조건에 쓴다.
- 저장 버튼 하나. 저장하면 상대 화면에도 바로 반영(실시간).

### 1.2 기존 대출

- 목록: 이름, 종류, 소유(공동/A/B, 이름 글자와 함께), 잔액, 금리, 남은 기간 또는 매달 내는 금액. 추가·수정·삭제(되돌리기).
- 종류: 주담대 / 신용대출 / 마이너스통장 / 자동차 할부 / 전세대출 / 기타.
- 마이너스통장은 **잔액 칸에 한도**를 적는다 (안내 문구로 알려 줌).
- 주담대·자동차 할부·기타는 남은 기간(개월)이나 매달 내는 금액 중 하나가 꼭 있어야 한다. 둘 다 있으면 매달 내는 금액이 먼저.
- "자산 메뉴에서 불러오기": 자산 메뉴의 부채 항목 중 아직 안 불러온 것을 이름·잔액·소유만 채워 추가한다 (종류는 기타, 금리 0). 금리·기간은 직접 고치라는 안내. 이미 불러온 항목(`asset_id`가 같은 것)은 다시 불러오지 않는다. 불러온 뒤 자산 메뉴 금액이 바뀌어도 자동으로 따라가지 않는다.
- 목록 아래 합계: 잔액 합, "1년에 갚는 돈(DSR 기준)" 합.

### 1.3 집 후보

- 매매 / 전세 두 칸(세그먼트)으로 나눠 본다. 처음엔 매매.
- 후보 추가·수정·삭제(되돌리기). 두 사람이 같이 보고 고친다 (실시간).
- 매매 입력: 이름(30자), 집값, 지역(규제지역 / 수도권 비규제 / 지방), 예상 금리, 만기(년, 1~30), 기타 비용(취득세·중개비 등 직접, 선택), 메모(500자, 링크 인식).
- 전세 입력: 이름, 보증금, 지역(같은 3가지, 규제지역과 수도권 비규제는 "수도권"으로 계산), 예상 금리, 기타 비용, 메모.
- 금리·만기를 비우면 기준값의 기본 금리(매매 4.0%, 전세 3.8%)·기본 만기(30년)를 쓴다.
- 지역 고르는 칸 아래 "규제지역 목록" 펼침: 지금 기준값에 적힌 목록을 보여 준다.
- 후보 카드: 이름, 가격, 지역, 그리고 **상품별 결과**를 줄마다:
  - 상품 이름, 가능 여부(가능 / 불가 + 이유 한 줄, 예: "소득 8,500만 원 초과")
  - 최대 금액 + 그 금액을 정한 기준(예: "LTV 40%에서 막혀요", "DSR 40%에서 막혀요", "상품 한도")
  - 한 달 상환액, 필요한 현금(가격 + 기타 비용 − 대출), 대출 뒤 DSR
  - 가능한 상품 중 가장 큰 금액의 줄을 "가장 많이 빌릴 수 있어요"로 표시. 불가 상품은 흐리게 아래로.
- 매매 상품: 은행 주담대, 디딤돌 신혼부부, 디딤돌 생애최초. 전세 상품: 은행 전세대출, 버팀목 신혼부부.
- 우리 정보·기존 대출·기준값을 고치면 모든 후보 결과가 바로 다시 계산된다 (결과는 저장하지 않음).

### 1.4 기준값

- 화면 아래 "기준값" 섹션: 묶음마다(은행 주담대, 스트레스 금리, 디딤돌, 은행 전세, 버팀목, 규제지역, 기본 금리·만기) 값·**확인한 날**·**출처**를 보여 준다.
- "수정"으로 값·확인한 날·출처를 고친다 (`/loans/rules` 화면). 묶음마다 "조사값으로 되돌리기".
- 앱이 가진 조사값보다 확인한 날이 6개월 넘게 지났으면 "오래된 기준이에요, 확인해 주세요" 표시.

## 2. 계산 규칙 (`lib/calc/loans.ts`, 순수 함수)

공통:
- 금액은 원 단위 정수, 대출 금액 결과는 **만원 단위로 버림**.
- 소득 = 두 사람 연소득 합. 소득이 0이면 DSR·DTI가 있는 상품은 "소득을 입력해 주세요"로 불가.
- 원리금균등 한 달 상환액: `P × r / (1 − (1 + r)^−n)`, r = 연금리/12, n = 개월. 금리 0이면 `P / n`.
- 원리금균등 역산(1년 상환 가능액 A → 최대 원금): `(A / 12) × (1 − (1 + r)^−n) / r`.

### 2.1 기존 대출의 1년 상환액 (DSR용)

| 종류 | 계산 |
| --- | --- |
| 주담대·자동차 할부·기타 | 매달 내는 금액 × 12, 없으면 잔액·금리·남은 기간으로 원리금균등 × 12 |
| 신용대출 | 잔액 ÷ 5 + 잔액 × 금리 (5년 나눠 갚는 것으로 봄) |
| 마이너스통장 | 한도 ÷ 5 + 한도 × 금리 (쓴 금액이 아니라 한도 전체) |
| 전세대출 | 무주택: 넣지 않음. 1주택: 잔액 × 금리 (이자만, 2025-10-29부터) |

- 신용대출 나눠 갚는 기간(5년)도 기준값으로 고칠 수 있다 (출처마다 5년·10년이 달라서).

### 2.2 매매

**은행 주담대** = min(LTV 한도, 금액 상한, DSR 한도)
- LTV: 규제지역 40%, 수도권 비규제·지방 70%. 생애최초는 수도권·규제지역 70%, 지방 80%.
- 금액 상한(규제지역·수도권 비규제만): 집값 15억 이하 6억, 15억 초과~25억 이하 4억, 25억 초과 2억. 지방은 상한 없음.
- DSR: (소득 × 40% − 기존 대출 1년 상환액)을 **예상 금리 + 스트레스 금리**, 만기(최대 30년)로 역산. 스트레스 금리: 규제지역·수도권 비규제 +3%p, 지방 +0.75%p. 기존 대출만으로 40%를 넘으면 "기존 대출로 DSR이 이미 넘어요"로 불가.
- 1주택 + 규제지역·수도권 비규제: 가능으로 계산하되 "기존 집을 6개월 안에 팔아야 해요" 안내.
- 설명 줄: "변동금리 기준 스트레스 금리예요. 고정·주기형 금리는 한도가 조금 더 나올 수 있어요." / "총대출이 1억 원 이하면 DSR이 적용되지 않아요."

**디딤돌 신혼부부** = min(집값 × LTV 70%, 3.2억, DTI 한도)
- 조건: 무주택, 합산 소득 8,500만 원 이하, 집값 6억 이하, 순자산 5.11억 이하. 어긋나면 첫 번째 이유로 불가.
- DTI 60%: (소득 × 60% − 기존 대출 1년 이자)를 디딤돌 금리(기준값, 기본 3.0%)·후보 만기로 역산. 스트레스 금리 없음.
- 안내: "전용 85㎡ 이하(수도권 밖 읍·면 100㎡) 조건과 방공제는 직접 확인해 주세요."

**디딤돌 생애최초** = min(집값 × LTV, 2.4억, DTI 한도)
- 조건: 무주택 + 생애최초, 합산 소득 7,000만 원 이하, 집값 5억 이하, 순자산 5.11억 이하.
- LTV: 수도권·규제지역 70%, 지방 80%. DTI는 신혼부부와 같다.

- 한 달 상환액: 은행 주담대는 예상 금리(스트레스 금리 없이), 정책대출은 디딤돌 금리로.
- 대출 뒤 DSR = (기존 1년 상환액 + 새 대출 1년 상환액(실제 금리)) ÷ 소득.

### 2.3 전세

**은행 전세대출** = min(보증금 × 80%, 5억)
- 이자만 내는 것으로 한 달 상환액 = 대출 × 예상 금리 ÷ 12.
- 1주택 안내: "1주택이면 보증기관 한도가 줄거나 안 될 수 있어요."

**버팀목 신혼부부** = min(보증금 × 80%, 수도권 3억 / 지방 2억)
- 조건: 무주택, 합산 소득 7,500만 원 이하, 순자산 3.45억 이하, 보증금 수도권 4억 / 지방 3억 이하.
- 한 달 이자는 버팀목 금리(기준값, 기본 2.0%)로.

- 필요한 현금 = 보증금 + 기타 비용 − 대출.

## 3. 데이터 (마이그레이션, RLS: 같은 가구만 읽기·쓰기, 실시간 구독)

금리는 0.01% 단위 정수(`rate_bp`, 4.25% → 425), 금액은 원 단위 정수.

**`loan_profiles`** (가구마다 한 줄, `household_id` 기본 키)
- `income_a`, `income_b` bigint ≥ 0, `home_status` text (`none`/`one`), `first_time` boolean, `rules` jsonb (기본 `{}`), `updated_by`, `updated_at`.

**`loan_debts`**
- `id`, `household_id`, `name` (1~20자), `kind` (`mortgage`/`credit`/`overdraft`/`car`/`jeonse`/`other`), `owner` (`joint`/`a`/`b`, 기존 표와 같음), `balance` bigint > 0, `rate_bp` int 0~3000, `months_left` int null (1~600), `monthly_payment` bigint null, `asset_id` null (자산 항목), `sort_order`, `created_by`, `updated_by`, `created_at`, `updated_at`, `deleted_at`.
- 같은 가구에서 삭제 안 된 `asset_id`는 하나만 (부분 유니크 인덱스).

**`loan_scenarios`**
- `id`, `household_id`, `name` (1~30자), `deal` (`buy`/`jeonse`), `price` bigint > 0, `region` (`regulated`/`metro`/`local`), `rate_bp` int null, `term_years` int null (1~30), `extra_costs` bigint ≥ 0 기본 0, `memo` (500자), `created_by`, `updated_by`, `created_at`, `updated_at`, `deleted_at`.

- 작성자·수정자·수정 시각은 DB 트리거가 채운다 (기존 표와 같은 방식). 삭제는 소프트 삭제, 조회는 `deleted_at is null`.

## 4. 테스트

- 단위(`lib/calc/loans.test.ts`): 각 제한(LTV·금액 상한·DSR·상품 한도·DTI)이 결과를 정하는 경우, 경계값(집값 15억·25억, 소득 8,500만, 집값 6억, 순자산 5.11억), 스트레스 금리 지역별, 기존 대출 종류별 1년 상환액, 만원 버림, 소득 0·기준값 누락.
- E2E(테스트 계정): 우리 정보 저장 → 새로고침 유지, 매매 후보 추가 → 결과 금액 → 삭제 → 되돌리기, 전세 후보 같은 흐름.
