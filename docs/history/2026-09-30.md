## 개선 — 웹 사이드바 접기 (사용자 요청, 2026-09-30)
- 사용자 선택: 완전히 숨기기 대신 아이콘만 남기기(64px)
- 펼친 사이드바 머리: 알림 종 옆 접기 버튼. 접힌 줄(`SidebarRail`): 펼치기, 알림 종, 내역 추가 +, 메뉴 아이콘(정기지출 미납 숫자), 내 아바타·연결 상태 점, 설정. 아이콘에 마우스·키보드 포커스를 올리면 오른쪽 이름표 (이름표가 잘리지 않게 접힌 줄 메뉴에는 스크롤 없음)
- 접힌 상태에서 Ctrl K → 펼치고 검색칸 포커스
- 기기마다 쿠키 `sidebar-collapsed`로 기억, 서버가 처음부터 맞는 폭으로 그려 새로고침 깜빡임 없음 (`lib/sidebar.ts`)
- 확인: lint·typecheck·단위 테스트 244개, E2E 전체 41개(새로: 접기 → 새로고침 유지 → 접힌 채 메뉴 이동·내역 추가 → Ctrl K로 펼치며 검색칸). PC에서 접힌 줄·이름표·펼친 머리 캡처 확인 (확인 뒤 펼친 상태로 되돌림)

## 개선 — 사이드바 계좌·카드 접기, 가운데 한 번에 스크롤 (사용자 요청, 2026-09-30)

- 위(로고·검색·내역 추가)와 아래(내 프로필·설정)는 고정, 가운데(메뉴 + 계좌·카드)는 한 덩어리로 스크롤
- "함께 보는 계좌·카드" 제목을 누르면 목록을 접고 폄(`aria-expanded`). 접으면 개수 표시. 기기마다 기억(localStorage, 저장이 안 되면 이번 화면만). 웹 사이드바와 폰 ☰ 메뉴가 같이 씀
- `components/layout/SidebarMethods.tsx`로 나눔
- 확인: lint·typecheck·단위 테스트, E2E 전체 40개(새로: 접기 → 새로고침해도 접힘 → 펼치기). PC 낮은 창에서 스크롤·접기 캡처 확인
