## 개선 — 사이드바 머리 줄·상대 접속 상태 (사용자 요청, 2026-10-02)
- 웹 사이드바 맨 위를 `사이드바 접기` · `감자밭` · 알림 종 순서로 바꾸고, 오른쪽 화면 제목 줄과 높이(69px)·아래 선을 맞춰 맨 위가 한 줄로 보이게 함. 접기 버튼은 접든 펴든 같은 자리(접으면 머리 줄에 펼치기만, 종은 아이콘 줄 맨 위)
- 맨 위 두 사람 아바타를 빼고, 사이드바 아래에 상대 줄(아바타 + 접속 점, 이름 + 기분, `접속 중`/`접속 안 함`)을 내 프로필 위에 둠. 접힌 사이드바·폰 ☰ 메뉴도 같음
- 접속 상태: Supabase Realtime Presence(`components/realtime/PresenceProvider.tsx`, 채널 `presence:<가구 id>`). 동기화 채널과 나눠서 접속 표시가 실패해도 동기화는 그대로. DB 변경 없음
- 일정 화면 `일정 추가` 버튼이 48px라 제목 줄이 4px 높던 것을 44px로 (Button 기본 높이가 `h-11`을 덮어써서 `h-11!`)
- 결정(사용자): 접속 상태는 지금 접속 중인지만(마지막 접속 시각 없음), 상대 줄이 내 줄 위, 머리 줄 순서는 접기 → 감자밭 → 알림
- 확인: lint·typecheck·단위 336개, E2E 전체 55개 통과(새 테스트: 상대가 열면 `접속 중`, 닫으면 `접속 안 함`). 테스트 계정으로 PC(펼침·접힘·다크)·폰 메뉴 사진 확인, 1024·1280px에서 15개 화면 머리 줄 높이를 재서 모두 69px로 같음
