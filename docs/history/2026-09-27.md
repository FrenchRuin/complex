## 개선 — 전체 기간 검색, 연월 선택, 날짜 달력 (사용자 요청, 2026-09-27)
- 전체 기간 검색: 검색어가 있으면 모든 달에서 찾음(최근 순, 올해가 아니면 연도 표시). 위쪽 요약 "‘스타벅스’ 검색 결과 23건 · 지출 ○원", "이번 달만 보기"로 좁히기, 100건씩 "더 보기". 사람·유형·카테고리·결제수단 필터와 함께 동작
- 금액 검색: 검색어가 숫자면(예: 12,000 / 12000원) 금액이 같은 내역도 찾음
- 연월 선택: 내역·통계 화면 제목("2026년 9월")을 누르면 연도 ‹ › + 12개월 버튼 창, "이번 달로"
- 날짜 달력: 내역 입력·문자 미리보기의 날짜를 폰 기본 창 대신 앱 디자인 달력으로. 오늘/어제 버튼, 키보드 화살표(하루·일주일) 이동
- 확인: 단위 테스트 153개, E2E 17개 통과, 폰 크기 화면 확인

## 개선 — 앱으로 설치 (PWA, F-53 일부를 앞당김, 사용자 요청 2026-09-27)
- `app/manifest.ts`: 이름 "우리 둘 가계부"(홈 화면 "우리 가계부"), 전체 화면(standalone), 세로, 테마색 primary
- 아이콘: 로고가 없어 도형으로 (primary 바탕 + 두 사람을 뜻하는 겹친 동그라미). `next/og`로 생성 — 탭 아이콘, 아이폰용 180, 안드로이드 192·512·maskable. 기본 Next.js 파비콘 제거
- 아이폰 전체 화면 설정(appleWebApp). 앱 정보·아이콘은 로그인 없이 읽히게 proxy 제외 목록에 추가
- 설정 → 앱으로 설치: 안드로이드 크롬은 `앱 설치` 버튼, 아이폰은 사파리 "공유 → 홈 화면에 추가" 순서 안내, 이미 앱이면 "앱으로 쓰고 있어요"
- 오프라인 사용(서비스 워커 캐시)은 넣지 않음: 두 사람이 같이 쓰는 앱이라 옛 데이터를 보여주면 헷갈릴 수 있음
- 확인: 크롬 설치 가능 검사 오류 0개, 배포용 빌드 성공, E2E 14개 통과
