- 처리 중 표시: 정기지출 체크 동그라미·메모 체크 칸은 저장하는 동안 도는 표시(다시 누를 수 없음), 알림 항목은 누른 뒤 화면이 넘어갈 때까지 도는 표시. "내역 추가 창 전환"은 기다림이 없어 뺌
- 폰 헤더: 아래로 스크롤하면 필터 줄(사람 필터 등)이 접히고 위로 조금만 올리면 다시 나옴. 제목 줄은 그대로, 웹은 변화 없음, "동작 줄이기"면 애니메이션 없음
- 반복 일정(F-19): 수정·삭제를 누르면 "이 일정만 / 반복 전체"를 고름
  - DB: `events.skip_dates`(빠진 회차), `events.detached_from`(떨어져 나온 일정), `set_event_occurrence_skipped()`, `detach_event_occurrence()`, 알림 종류 `event_occurrence_deleted`·`event_occurrence_restored`
  - 이 일정만 삭제는 되돌리기 가능. 이 일정만 수정은 한 번짜리 일정이 되고, 떼어 내는 순간에는 알림 없이 고친 내용만 "수정" 알림
- 확인: 단위 테스트 214개, E2E 전체 32개(새로 5개: 90일 정리, 폰 달력 넘침, 폰 필터 접기, 반복 일정 화면 흐름, 반복 일정 DB 규칙. 체크 풀기 알림은 기존 알림 규칙 테스트에 추가), lint·typecheck 통과. 폰 크기로 범위 선택·이 일정만 수정 창·처리 중 표시 캡처 확인
